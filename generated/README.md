# Generated Views

Files in this directory are disposable navigation and review surfaces built from canonical knowledge.

Typical outputs:

- `CONTEXT_MAP.md` — compact progressive-disclosure routing view;
- `INDEX.md` — complete canonical object listing;
- `OPEN_QUESTIONS.md` — unresolved question view;
- `FRESHNESS_QUEUE.md` — due/upcoming review targets;
- `REVIEW_QUEUE.md` — consequential conflicts or ambiguity requiring review.

Generated files are never the source of truth. They may be deleted and rebuilt.

Start with `CONTEXT_MAP.md` when you need orientation, then descend into the relevant canonical objects rather than loading the entire corpus.
