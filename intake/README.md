# Intake

This is the low-friction landing zone for raw material that has not yet been canonicalized.

Examples: rough meeting notes, transcript extracts, document drops, research snippets, or batch sweep inputs.

Material here is **not canonical knowledge**. Agents should use the capture/sweep skills to promote durable information into `knowledge/` and preserve only the raw source material that has ongoing evidentiary value.

In the public starter, do not place non-public Elsevier information here.
