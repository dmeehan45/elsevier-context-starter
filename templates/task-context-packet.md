# Task Context Packet

This is a derived handoff artifact for work executing outside the repository. It is not canonical knowledge and does not grant permissions or define runtime controls.

## Objective

State the outcome to investigate, verify, map, compare, or report.

## Questions / Verification Targets

- What must the external worker answer?
- Which existing assumptions or records especially need verification?

## Relevant Existing Context

For each important item, include the stable canonical ID and a concise current-state summary.

- `canonical-object-id` — current understanding, status/confidence, relevant date

## Known Conflicts / Freshness Concerns

List disputed, stale, provisional, or time-sensitive items that may affect the investigation.

## Relevant Sources / Evidence

Point to source IDs or external evidence that the worker should understand when those references are available to its runtime.

## Expected Return

Return a report that separates:

1. direct observations;
2. evidence/source references;
3. inference or interpretation;
4. unresolved/access-limited areas;
5. proposed confirmations, refinements, supersessions, contradictions, questions, or new knowledge.

Use `templates/run-report.md` when practical.

## Runtime Boundary

Execute only within the permissions, tools, identity, sandbox, compliance rules, and approval model supplied by your runtime. This packet does not add permissions. If a required capability is unavailable, report the limitation rather than bypassing it.
