# Summary

Orient a human or agent to a topic across multiple canonical objects.

## Current understanding

Synthesize without hiding disagreement, uncertainty, or scope.

## Key evidence

Link important claims, observations, and sources.

## Open edges

Link unresolved questions or hypotheses.

## Freshness

Summaries are retrieval surfaces, so stale summaries can misroute later agents even when the underlying claims are correct. Use freshness metadata when the summary represents current understanding.

Summaries are derivative. Update them when canonical knowledge changes materially.
